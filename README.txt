GITHUB PAGES SETUP
==================

1. Create a new GitHub repository.
2. Upload ALL files in this folder to the repository root.
3. Make sure index.html is in the repository root.
4. Go to Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select your main branch and the / (root) folder, then Save.
7. Open the GitHub Pages URL after deployment finishes.

The HTML has been updated to use the uploaded media filenames with exact capitalization,
so it works with GitHub's case-sensitive file paths.

Note: Snapchat-1341028966.mp4 is included as an extra uploaded video but is not currently
referenced by index.html.
